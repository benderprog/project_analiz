# Тестирование

## Unit-тесты (SQLite по умолчанию)

Для быстрых unit-тестов Postgres не требуется. Запуск через `manage.py test`
по умолчанию переключается на SQLite in-memory, чтобы избежать проблемы с
правами `CREATEDB` в окружениях без привилегий.

```bash
python manage.py test
```

Для удобства есть скрипт и Makefile:

```bash
./scripts/test.sh
# или
make test
```

## Как принудительно использовать Postgres в тестах

Если нужен прогон тестов на Postgres (например, интеграционные проверки),
явно укажите стандартные настройки:

```bash
DJANGO_SETTINGS_MODULE=config.settings python manage.py test
```

## Семантическая модель

Во время unit-тестов загрузка моделей отключена автоматически, чтобы не
скачивать тяжелые зависимости. При необходимости можно переопределить это,
установив переменную `SKIP_SEMANTIC_MODEL=false` и запустив тесты с нужными
настройками.
