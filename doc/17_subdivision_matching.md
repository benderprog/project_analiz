# Сопоставление подразделений v2

## Источник данных

- Источник истины: `portal_db.subdivision` (модель `portaldb.Subdivision`).
- Кэш приложения: `analysis_app.CachedSubdivision` в основной БД.

## Шаги сопоставления

1. **Нормализация текста**
   - Нормализуем текст абзаца и `Subdivision.short_name` (если пусто — `Subdivision.name`).
   - Дополнительно сохраняем нормализованный ключ для `Subdivision.name`.
   - Правила нормализации: нижний регистр, унификация кавычек/тире/№, схлопывание пробелов,
     удаление хвостовой пунктуации и скобок.
   - Символ `№` канонизируется так, что `№1` и `№ 1` становятся эквивалентными.

2. **Подстрочное совпадение (primary)**
   - Ищем точное подстрочное вхождение нормализованного `short_name`.
   - Если не нашли — проверяем нормализованный `name`.
   - При совпадении возвращаем метод `substring`, позицию (span) и подразделение.

3. **Семантическое окно (fallback)**
   - Если подстрочное совпадение не найдено, строим токенизированные окна (1–6 токенов,
     максимум 80 окон) без регулярных выражений.
   - Окна сравниваются с эмбеддингами подразделений.
   - Возвращаем метод `semantic_window`, окно и оценку, если превышен порог
     `SUBDIVISION_SEMANTIC_THRESHOLD`.

## Кэширование эмбеддингов

- Эмбеддинг рассчитывается на основе `Subdivision.short_name`.
- Если `short_name` пуст, используется `Subdivision.name`.
- Нормализованный источник для эмбеддинга вычисляется из `short_name` (fallback на `name`).
- Для подстрочного совпадения используются `CachedSubdivision.normalized_short_name`
  и `CachedSubdivision.normalized_name`.

## Обновление кэша

Команда для ручной синхронизации:

```bash
python manage.py sync_subdivision_cache --rebuild-embeddings
```

Также кэш обновляется при сохранении `portaldb.Subdivision` через сигнал.

## Troubleshooting

- **Подразделение не найдено:** проверьте `short_name` в `portal_db` и выполните
  `python manage.py sync_subdivision_cache --rebuild-embeddings`.
- **Семантические совпадения не работают:** убедитесь, что модель доступна и
  `SKIP_SEMANTIC_MODEL` выключен.
