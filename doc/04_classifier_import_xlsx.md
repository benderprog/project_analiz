# Импорт классификатора из XLSX

## Формат
XLSX-файл должен содержать 3 колонки:
1. Тип события
2. Паттерн
3. Статья КоАП

Первая строка — заголовок.

## Правила заполнения (fill-down)
- Пустые значения берутся из последнего непустого значения по колонке.
- Если после fill-down поле `Тип события` всё ещё пустое — строка пропускается.
- Полностью пустые строки игнорируются.

## Пример
| Тип события | Паттерн | Статья |
| --- | --- | --- |
| Нарушение A | паттерн 1 | 12.1 |
|  | паттерн 2 |  |
|  |  | 12.2 |

Результат:
- Нарушение A / паттерн 1 / 12.1
- Нарушение A / паттерн 2 / 12.1
- Нарушение A / паттерн 2 / 12.2

## Импорт в админке
В админке `Event type classifiers` нажмите "Import xlsx" и загрузите файл. Можно опционально очистить текущие записи перед импортом.
