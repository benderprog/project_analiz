# Импорт классификатора из XLSX

## Формат
XLSX-файл должен содержать 3 колонки строго по порядку:
1. Тип события (event_type)
2. Паттерн (pattern)
3. Статья КоАП (article)

Первая строка — заголовок.

## Правила заполнения
- Полностью пустые строки игнорируются.
- Тип события читается из колонки A.
- Паттерн читается из колонки B. Паттерн может быть пустым, тогда создается только тип.
- Статья КоАП читается из колонки C и сохраняется только на уровне паттерна.
- Для совместимости допускается fill-down только по типу события: если в строке нет типа, но есть паттерн/статья, используется последний непустой тип.
- Если тип события пустой после этой проверки — строка пропускается.
- Если паттерн пустой — запись паттерна не создается.

## Пример
| Тип события | Паттерн | Статья |
| --- | --- | --- |
| Нарушение A | паттерн 1 | 12.1 |
|  | паттерн 2 |  |
| Нарушение B |  |  |

Результат:
- Создан тип `Нарушение A` с паттернами `паттерн 1` (12.1) и `паттерн 2` (без статьи).
- Создан тип `Нарушение B` без паттернов.

## Импорт в админке
В админке `Event types` нажмите "Импорт из XLSX" и загрузите файл. Можно опционально очистить текущие записи перед импортом.
